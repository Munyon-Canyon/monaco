- 2026-10-06: Built the Ably publish and the token route (#623). `ABLY_API_KEY` is required in staging and production and optional elsewhere, where an empty key makes the publish a no-op and the token route answers `upstream_unavailable`. `ABLY_REST_HOST` takes a host or a full URL, because the REST client rewrites every request onto the shared HTTP client's base URL and `cmd/fakes` serves Ably under `/ably`. The timeout is `MONACO_TIMEOUT_ABLY` (2 s). The publish runs after the `uow.Do` commit, and `thread.updated` reads the parent's `reply_count` from the bump itself.
- 2026-10-06: Built `MarkChatSeen` and the throttled `seen.updated` publish (#673). The 5 s throttle is the `chat_seen.seen_published_at` column, claimed by one guarded `UPDATE` after the commit, so it holds across API instances and runs on the fake clock. The claim, the newest channel message and the count run as one statement, and a chat with no channel message does not use up the throttle.
